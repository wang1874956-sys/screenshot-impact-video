# 主体、分层与镜头

## 先决定画面让观众看什么

为每段选一个焦点。主角可以是一个图标、一张完整卡、一个人或一处景；其他元素服务于它。写下入场前后主体在哪里、观众何时能看清、下一段焦点为什么转移。原图信息密集时减少被拆出的元素，不要求每项都独立运动。

以素材本身定视觉语言：颜色、形状、光效、透视和装饰取自原图。游戏奖励图可以延展奖励图标的颜色、画框和庆祝碎片；软件截图沿用界面结构；实景照片顺着光线和前后景。不要给每张图套同一片深色空舞台、圆环和冲屏节奏。

## 选图层，不只选矩形

| 原图元素 | 优先处理 |
| --- | --- |
| 有完整边框、底板或透明底的 UI 卡片和图标 | 可以整体裁出并移动；预览放大后的边角 |
| 标题、说明和密集文字 | 尽量留在所属面板；必须单独运动时保留合适的原有底板或在新面板中忠实重排，不能带出突兀矩形 |
| 不规则角色、装饰画框、实景物体 | 轮廓蒙版、透明图层或局部运动；检查毛发、金边、反光和被遮挡的部位 |
| 会露出原位置的主体 | 使用经过检查的干净背景、局部修复或镜头遮挡；不能留下重影或硬色块 |

裁片入场时的运动模糊、阴影和闪光只用来增强速度与空间感，不能掩盖未处理的白底、断边或矩形角。一个完整面板自然移动，通常好过把面板上的每段文字都切下来飞。

手机桌面若同时有大组件与应用图标，先把含照片或文字的组件视为完整面板，让组件交替成为焦点；图标可以承担更快、更不规则的过渡。不要把组件中的人物、日期或天气文字拆成会破坏可读性的碎片。检查前后遮挡：非焦点组件可退后，但不能无意裁掉人脸或关键文字。开场或收尾淡入原图前，先让独立图层、镜头缩放和位移复位，避免双影。

## 镜头与节奏

把每段写成“焦点—动作—停顿—下一段动机”。主角冲近之后留出能辨认它的时间；第二次冲击换方向或景别，不让全部元素持续同频运动。镜头移动与局部动作错开一些，避免画面始终晃动。近景要让主体足够清晰，远景要让构图不空。

对照片，整体镜头运动与动物、海浪等主体自身运动是不同能力。若用户明确要后者，按 [照片与自然运动](photo-and-natural-motion.md) 选择可用工具并验证，不把平移放大说成真实动作。
